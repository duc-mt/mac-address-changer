# Security Policy

## Supported Versions

Currently, only the latest version of `macmorpher` on the `master` branch is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within `macmorpher`, please open an issue or send an email to the repository owner. 

We take all security vulnerabilities seriously and will try to respond to all inquiries within 48 hours. Please do not disclose the issue publicly until a patch is released.
